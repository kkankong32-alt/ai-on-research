# AI-ON 과학탐구 기록장

초등 과학탐구의 사전·사후·지연 검사, 성찰저널, AI 대화 기록을 프로젝트와 익명 학생 ID로 연결하는 연구용 웹앱입니다.

## 팀 공유 미리보기

공유 주소: https://kkankong32-alt.github.io/ai-on-research/

2026-10-05 사용자의 공개 허용에 따라 GitHub Pages 배포를 사용합니다. 아래 로컬 전용 안내는 이전 보관 방식이며, 현재는 공개 코드와 웹사이트를 함께 제공합니다. 첫 화면의 ‘개발 미리보기’에서 학생·연구관리 화면을 로그인 없이 확인할 수 있습니다. 미리보기 기록은 메모리에서만 유지되며 새로고침하면 사라집니다. 실제 로그인·저장은 Firebase를 사용하며 운영 전 실서비스 검증은 여전히 필요합니다.

GitHub Actions가 단위검사와 보안 규칙 에뮬레이터 검사를 통과한 뒤 빌드·배포합니다. Firebase 웹앱 공개 설정만 저장소 Variables로 공급하며 관리 토큰·서비스계정 키·학생 원자료는 저장소에 포함하지 않습니다.

## 실행

Node 22+, Java 21+ 필요(보안 규칙 테스트).

```sh
npm ci
cp .env.example .env.local
npm run dev
npm test
npm run test:rules
npm run build
```

Firebase 웹앱 설정은 `.env.local`로 공급합니다. 서비스 계정 키는 필요하지 않습니다. 최초 관리자 등록은 승인된 프로젝트 소유자의 권한으로 수행하고 일반 앱에서 자동 승격하지 않습니다.

## 데이터와 권한

- Google 로그인 + 등록 연구회원 목록을 서버 규칙에서 확인합니다.
- 학생은 익명 Auth + 랜덤 개인코드로 자기 프로젝트·학생 범위만 접근합니다.
- 제출 후 수정 잠금, 교사 재개방, revision 스냅샷을 적용합니다.
- 익명 CSV는 실명 매핑·개인코드를 제외합니다. 자유서술에 포함된 이름은 자동 제거하지 않습니다.
- Firestore가 원본 저장소입니다. localStorage는 미전송 초안 용도입니다.
- 개발 미리보기는 `npm run dev`에서만 제공되고 운영 빌드에서는 제거됩니다.

## 파일

`src/components`: 학생/연구자 UI, `src/services`: 인증·원격 저장, `src/data`: 검사·코드북 원본, `src/utils`: 점수·CSV·파서, `firestore.rules`: 접근 및 무결성 검증, `tests`: 단위·Rules 테스트, `docs/architecture.md`: 원본 분석 및 설계.

## 운영

Firebase 프로젝트: `ai-on-research-2026-kk21`. Firestore: 서울 `asia-northeast3`, Spark 무료 할당량. Cloud Functions/결제/Analytics 없음. Google 및 익명 인증을 사용합니다. 사용자 요청에 따라 코드와 연구도구는 로컬에만 보관하며 자동 공개 배포 설정을 제거했습니다. 실행은 `START.cmd`를 열고 Chrome 또는 Edge에서 http://127.0.0.1:5173 에 접속하세요. Node.js 22 이상이 필요합니다. 제공된 dist는 이미 빌드되어 npm 설치 없이 실행할 수 있습니다.

**로컬 실행은 오프라인 전용이라는 뜻이 아닙니다.** 인증과 연구자료 저장에는 연결된 Firebase 및 인터넷을 사용합니다. 로컬 주소·QR은 다른 기기로 접속할 수 없습니다. 학생의 여러 기기에서 사용하려면 별도의 비공개 접근 방식 검토가 필요합니다.

```sh
firebase deploy --only firestore --project ai-on-research-2026-kk21
```

규칙 변경은 Emulator 테스트 후 별도 배포합니다. 결과물에 Firebase 관리 키나 토큰을 저장하지 않습니다. 사용량 한도에 도달하면 저장 오류가 표시되며 유료 요금제로 자동 전환하지 않습니다.

## 연구도구 주의사항

검사 문장은 제공 보고서 12쪽 및 HTML에서 보존했습니다. E5만 6−원응답으로 별도 역채점합니다. 정성 자동코딩과 루브릭은 휴리스틱 초안이며 교사의 확정 판단과 분리합니다. 내용타당도 기존 CVR은 적합성 3·4점 비율로 계산된 지수이며 전통적 필수성 CVR과 구분합니다. 통계적 유의성·효과성을 자동 결론내리지 않습니다.

## 2026-10-12 연구도구 개정

새 프로젝트에는 `ai-on-feedback-2026-v2`(26문항)를 적용합니다. 기존 프로젝트는 버전 필드가 없어도 `ai-on-report-2026-v1`(28문항)로 읽습니다. 기존 응답·초안·전문가 검토·연구회원·접속정보를 변경하거나 삭제하는 데이터 이관 작업은 없습니다. 프로젝트의 도구 버전은 변경할 수 없으며, 개정판 연구는 새 프로젝트에서 시작합니다.

- 개정판은 기존 A5와 D1을 제외합니다. 표시 번호는 기존 A6 → A5, 기존 D2~D5 → D1~D4입니다. 원자료의 내부 식별값은 바꾸지 않습니다.
- B6, J3 안내, Q-HYP 예시는 피드백 PDF의 파란색 수정안을 반영합니다. 기존판 문구와 교사가 설정한 차시별 질문, 제출 당시 질문은 보존합니다.
- 개정판 영역별 문항 수는 A 5 / B 6 / C 6 / D 4 / E 5입니다. E5만 `6 - 원점수`로 계산하며, 영역 내 결측이 있으면 평균은 비웁니다. 검사 문항 수와 탐구 여정의 활동 수는 별개입니다.
- ‘자료 내보내기’의 검사 CSV에는 도구 버전과 문항 수가 추가됩니다. ‘연구도구 문항표’ CSV에서 원자료 식별값과 화면 번호·문구를 대응시킬 수 있습니다. 기존판·개정판 점수를 구분하여 분석합니다.
- 내용타당도 검토와 집계는 프로젝트 버전을 따릅니다. 기존 전문가 평정은 개정 문항의 평정으로 전환하지 않습니다.
- 짧은 동의 발화의 R-ACCEPT 자동분류는 맥락 검토가 필요한 초안입니다. ‘차시별 변화’에서 발화 통계를 교사 확정값만으로 볼 수 있고, CSV에도 자동/교사 구분과 맥락 검토 필요 여부가 기록됩니다. 도전 점수는 학생별 변화와 과제 수준을 함께 해석합니다.

배포 순서: 단위검사 → Firestore 에뮬레이터 검사 → 빌드 및 학생·연구자 미리보기 확인 → 두 버전을 지원하는 Firestore 규칙 배포 → GitHub Pages 배포. 규칙 배포는 회원이나 연구자료 문서를 수정하지 않습니다. 공개 저장소에 원자료 백업을 포함하지 않습니다. 이전 설명서의 28문항 설명은 기존판에 해당하며, 개정판 문항은 앱의 문항표 CSV를 기준으로 확인합니다.
