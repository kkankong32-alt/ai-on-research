# AI-ON 로컬 실행 안내

**팀 공유 배포 추가:** https://kkankong32-alt.github.io/ai-on-research/ 에서 설치 없이 확인할 수 있습니다. 첫 화면의 개발 미리보기에서 학생·연구관리 화면을 선택하세요. 사용자가 2026-10-05 공개를 허용하여 이전 로컬 전용 방침을 변경했습니다. 아래 로컬 실행 방법도 계속 사용할 수 있습니다.

1. `START.cmd`를 두 번 클릭합니다. Node.js 22 이상이 설치되어 있어야 합니다. 실행 창은 열어 둡니다.
2. Chrome 또는 Edge에서 `http://127.0.0.1:5173`을 엽니다. 인터넷 연결이 필요합니다.
3. 연구자 로그인에서 `kkankong21@gmail.com`으로 로그인합니다. 이 계정만 최초 총괄관리자로 등록되어 있습니다.
4. 프로젝트 만들기에서 차시 수, 사용할 검사·기록 종류, 학생 수를 설정합니다. 실명 없이도 운영할 수 있습니다.
5. 개인 접속코드를 발급해 안전하게 보관합니다. 학생 화면에서 코드로 들어가 사전검사 → 차시 기록 → 사후검사를 진행합니다. 지연검사는 연구자가 엽니다.
6. 연구자 화면에서 진행 현황, 개별 기록, 자동코딩과 교사 확정 코딩을 확인합니다. 자동코딩은 교사 검토가 필요한 초안입니다.
7. 익명 CSV와 연구자료 JSON 백업을 내려받아 별도로 보관합니다. JSON 연구 백업에는 실명 대응표와 접속코드가 포함되지 않습니다. 자유서술 속 개인정보는 내보내기 전에 확인합니다.

## 차시와 학생 탐구 여정 설정

프로젝트 생성 또는 설정에서 총 차시 수(1~30), 사전·사후·지연검사 사용 여부를 선택합니다. 기본 선택은 모든 차시에 탐구 돌아보기/AI 대화 기록을 사용하는 방식입니다. `차시별로 다르게 설정`을 펼치면 각 차시의 기록 종류를 따로 켜고 끌 수 있습니다. 설정 화면의 ‘학생 활동 총 N개’와 학생 진행률은 사용 중인 활동만 계산합니다. 사전/사후와 저널/AI를 모두 사용하면 3차시는 8개, 6차시는 14개입니다.

프로젝트 설정 아래 운영 설정에서 각 차시를 `순차 진행`, `수동 열기`, `잠금`으로 정합니다. 순차 진행은 사전검사와 이전 차시의 사용 활동이 모두 제출되면 열립니다. 같은 차시의 두 활동은 함께 열립니다. 수동 열기는 이전 활동 완료 여부와 관계없이 해당 차시를 엽니다. 사용하지 않는 활동은 열지 않습니다. 차시 수를 줄이거나 기록을 끄더라도 기존 원자료는 삭제하지 않습니다. 설정 복제 시 수동 열기와 잠금은 순차 진행으로 초기화합니다.

학생 상단 버튼은 접근 가능한 첫 미완료 활동으로 연결됩니다. 남은 활동이 모두 잠겼으면 다음 탐구 안내만 표시됩니다.

## 실행 범위

코드와 검사도구는 공개하지 않았습니다. 로컬 앱의 인증·저장은 Firebase를 사용합니다. 파일을 더블클릭해 index.html만 여는 방식은 지원하지 않습니다.

127.0.0.1은 현재 컴퓨터만 가리킵니다. 이 주소의 QR이나 링크를 다른 태블릿에서 열 수 없습니다. 현재 결과물은 연구자 컴퓨터의 로컬 검토용입니다. 다기기 현장 운영은 배포 방식과 실기기 검증이 추가로 필요합니다.

## 저장 문제

미전송 초안은 작성 기기에 임시 보관됩니다. 저장 완료 표시를 확인한 뒤 창을 닫으세요. 다른 기기와 충돌하면 초안을 내려받아 보관하고 최신 기록을 확인합니다. 기기 저장소를 지우거나 학생 전환을 하면 미전송 초안이 사라질 수 있습니다.

Google 로그인 오류가 나면 일반 Chrome/Edge에서 확인하세요. 앱 내 브라우저에서 발생한 네트워크 오류는 아직 해결 여부가 확인되지 않았습니다. 로그인 성공 및 실제 저장을 확인하기 전에는 실제 학생자료를 입력하지 마세요.
